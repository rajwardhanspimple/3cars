Automatic gears. ABS and traction control are always on. Use Space to start a manual drift, steer through the corner, then use Shift for exit boost.

Boost lasts about 4 seconds from a full meter, then has a 2 second cooldown. It recharges at about 18 points per second, so a full refill takes about 5.6 seconds.

Track cuts add 5 seconds. If you skip a checkpoint, you still get the warning and teleport back. That lap stays invalid and the record does not count. Keep going and the next lap works normally. Press R to recover manually for +20 seconds.

Desktop keyboard required. This branch is a mountain preview only. It is not the final main release. All three cars use the same full-detail Mustang geometry. Visual approval is still required before publish.
